# 场景与反例

12小时观测，每小时三处设备、三组两两重叠记录。首小时A120、B110、C90，交集40、30、20，可行联合人数230至250。A100、B80、交集30时联合人数150。A、B、C都100但AB80、AC80、BC0，无可行三方交集，必须隔离。脏样例含缺测、同版冲突、BOM、短行、重复与中文换行。

时钟漂移样例 `drift.csv`：设备D1慢13分钟，真实11:00的观测被读成10:47（与09:00组相差不足一小时）。不校准时第二组归入02:00Z桶、联合区间被拆小时；提交 `clock_rules=[{device_id:D1,offset_minutes:13,evidence_id:EVD-1}]` 后回到03:00Z真实小时桶。证据非法时整批回退、返回422，旧归档保留；同批证据重跑 run_id 不变，不新增归档版本。
